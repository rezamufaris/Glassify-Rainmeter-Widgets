# Glassify - Glassmorphism Rainmeter Widgets

![Glassify Banner](https://via.placeholder.com/1200x400/0f172a/06b6d4?text=Glassify+Rainmeter+Suite)

**Glassify** is a modern *desktop dashboard suite* for Rainmeter with a simple and clean **Frosted Glass (Acrylic)** UI style. It is specifically designed with a standard width of 375px, consistent grid proportions, and modern *typography* using the **Plus Jakarta Sans** font.

## ✨ Features & Widgets

- **Acrylic Windows UI Style**: Uses realistic Acrylic effects with the `FrostedGlass.dll` plugin.
- **Calendar**:
    - Monthly calendar with dynamic active day markers (*circle highlight*).
    - Available in **Normal (375px)** and **Small (180px)** variants.
- **Daily Brief**: A concise daily summary to greet users and provide short quotes.
- **Network**: Real-time monitoring of internet connection speeds (*Upload* & *Download*).
- **Power**: Battery status indicator, charging status (AC Power), and battery percentage.
- **Quick Notes**: Displays up to **3 key notes** neatly and concisely.
- **Hardware Sensors**: In-depth monitoring of temperature and performance of hardware components (CPU, GPU, RAM).
- **System Monitor**: Real-time indicators for **RAM** and **Storage** with *dynamic circular rings*.
- **Weather**:
  - Available in **Normal (375px)** and **Small (180px)** variants.
  - Uses the stable and accurate **Open-Meteo** API (free of third-party dependencies).
- **⚙️ Centralized Variables**: User name, accent color, card radius, and typography configurations are centralized in `Variables.inc`.

## 🛠️ Installation

1. Make sure you have installed **[Rainmeter 4.5](https://www.rainmeter.net/)** or a newer version on Windows.
2. Download the latest official installer file from the **[Releases](../../releases)** page (`Glassify by Rez Creative_1.0.0.rmskin`).
3. Double-click the `.rmskin` file, then click **Install**.
4. All Glassify widgets and `FrostedGlass` plugins will be installed automatically!
## ⚙️ Configuration & Customization

Glassify offers several customization options to tailor the widget to your needs and desktop setup.

📖 **Complete customization & configuration guide:**

👉 [Read the Customization Guide](CUSTOMIZATION.md)

The guide covers:

- Changing **Global Variables** such as username, font, color, and card radius.
- Editing and adding notes to **Quick Notes**.
- Changing the city location and coordinates in **Weather**.
- Changing the SSD/HDD storage labels in **System Monitor**.
- Changing the greeting messages and quotes in **Daily Brief**.
